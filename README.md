# ひろい姫 — 金属サイディング 図面拾い・積算（単体Webアプリ版）

Claudeとは無関係に動く、サーバー不要の静的Webアプリです。
このフォルダをそのまま置くだけで動きます（index.html / app.js / calc.js / manifest.json / sw.js / icon-*.png）。

## 公開する一番かんたんな方法（無料）
1. https://app.netlify.com/drop を開く（無料アカウント作成）
2. このフォルダをドラッグ＆ドロップ
3. 発行されたURL（https://xxxx.netlify.app）をスマホで開く
   - iPhone：共有ボタン →「ホーム画面に追加」でアプリとして起動
   - Android：メニュー →「ホーム画面に追加」

GitHub Pages / Cloudflare Pages / Vercel でも同じ（フォルダを置くだけ）。
自社サーバーなら、HTTPSで配信できる場所にフォルダをアップロードすればOK。

## 注意
- データ（拾い・材料マスタ・単価）は**その端末のブラウザ内**に保存されます。端末を変えるときは ④「マスタをコピー → 貼り付けて取込」で移せます。
- PDF表示（pdf.js）とフォントはCDNから読み込みます。初回はネット接続が必要。2回目以降はオフラインでも動きます（sw.jsがキャッシュ）。
- 1/100原寸でないPDFや写真は、②の「2点合わせ」でスケールを取ってください。
- 複数人で同じ案件を共有したい／会社で一元管理したい場合は、バックエンド（Firebase等）の追加が必要です。

## ファイル

- calc.js … 積算ロジック（純関数。働き幅・定尺・ロス率はここの既定値と④の材料マスタ）
